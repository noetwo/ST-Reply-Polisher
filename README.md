# 正文优化

SillyTavern 第三方扩展：AI 回复生成后，将指定 XML 标签（默认 `<content>`）中的正文交给独立的 OpenAI 兼容模型优化，并可安全写回原楼层。

## 功能

- 只支持 OpenAI 兼容接口，通过 SillyTavern 后端代理请求。
- API 地址、模型、最大 Token、温度、上下文条数和超时均可调整；温度和上下文条数可设为 `0`。
- 可编辑破限提示词、任务规则和输出格式补充。
- 可引用当前角色世界书或手动选择世界书。
- 排除内容使用占位符保护；占位符缺失、被修改或重复时，整次写回取消。
- 请求返回后会复核聊天、楼层对象和原文；切换聊天、编辑、删除或滑动消息后，过期结果不会写回。
- 请求失败、超时、返回为空或格式校验失败后，可用“重试上次失败”再次处理同一条原文。
- 扩展菜单提供最近一次优化的前后 Diff。

## 从 GitHub 安装

1. 确保 `manifest.json` 位于 GitHub 仓库根目录。
2. 在 SillyTavern 的「扩展」页面选择「安装扩展」。
3. 粘贴仓库 URL：`https://github.com/noetwo/ST-Reply-Polisher.git`。
4. 安装完成后刷新页面，在扩展设置中打开「正文优化」。

也可以把仓库目录放到：

```text
SillyTavern/data/<用户名>/scripts/extensions/third-party/<目录名>
```

## 配置

1. 填写 OpenAI 兼容 API 地址，例如 `https://example.com/v1`。也可填写完整的 `/chat/completions` 地址。
2. 填写 API 密钥和模型 ID，点击「测试连接」。密钥仅保存在当前标签页的 `sessionStorage`，刷新后需要重新输入。
3. 确认目标标签和提示词，然后打开顶部开关。
4. 默认开启写回；若只想查看结果，可关闭「优化结果写回消息」。

排除规则每行一条：

```text
开始标记|||结束标记
<StatusPanel>|||</StatusPanel>
```

## 自检

无需安装依赖：

```bash
npm test
```

## 范围

本仓库不包含授权码、统计、更新检查、Google 直连、SillyTavern 当前主连接复用、表格、记忆/RAG、剧情推进或原版配置迁移。
